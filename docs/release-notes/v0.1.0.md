# Evidence Change Monitor v0.1.0

Initial public release.

## Included

- strict source registry;
- text, HTML, JSON, RSS, and Atom normalization;
- evidence-preserving change events;
- severity rules;
- versioned state and last-known-good retention;
- JSON, Markdown, HTML, and CSV reports;
- integrity manifests;
- synthetic multi-source demonstration;
- Python 3.11–3.13 CI and reproducible release assets.

## Boundary

The release processes explicit local captures. It does not fetch external sources, access private accounts, send notifications, or certify the truth or materiality of detected changes.
