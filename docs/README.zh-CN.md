# Evidence Change Monitor 中文说明

这是一个证据优先的变化监测工具。它比较**明确提供的本地快照**，而不是在后台秘密联网。

系统严格区分：

- 原始内容和标准化内容都没有变化；
- 原始字节变化，但被明确的标准化规则忽略；
- 监测范围内出现结构化变化；
- 输入缺失、过大、读取失败或解析失败；
- 没有可用历史基线，当前内容只是首次出现。

第一版支持文本、HTML、JSON、RSS 和 Atom；输出 JSON、Markdown、HTML、CSV 与 SHA-256 完整性清单。

## 重要边界

检测到变化，只能证明两个快照在监测口径内不同，不能自动证明：

- 来源内容真实；
- 现实状态已改变；
- 改变具有法律效力；
- 改变由某个原因造成；
- 改变对某个业务决策具有实质影响。

没有检测到变化，也不等于外部世界没有变化。

网络获取、账号凭据、浏览器 Cookie、私有地址和消息推送均不属于 v0.1.0 核心。
